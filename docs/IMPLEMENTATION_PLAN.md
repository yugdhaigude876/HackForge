# Implementation Plan

Sequence kept as specified; no research finding required reordering. Each phase: objectives, modules, acceptance, tests.

| Phase | Objective / features | Modules | Acceptance & tests |
|---|---|---|---|
| 1 Foundation & design system | Next.js + strict TS, Tailwind, shadcn/ui, dark theme, app shell, KPI cards, chart/table containers, loading/empty/error states, sample-data dashboard | `src/app`, `src/components/{layout,ui,finance}`, `src/lib/sample-data.ts` | lint, `tsc`, build pass; nav works; responsive; sample data labelled |
| 2 Firebase auth & DB | Sign-in, token verify, org membership, Firestore repos, rules | `src/lib/firebase-client.ts`, `src/server/*`, `firestore.rules` | rules tests via emulator; unauthenticated API returns 401 |
| 3 Transactions & synthetic data | Money module, seeded generator, hourly aggregation | `src/engine/{money,synthetic}` | determinism by seed; money property tests |
| 4 Forecasting | Seasonal naive, hour-of-week smoothing, backtest, quantiles | `src/engine/forecast` | beats-or-reports-vs baseline; MASE/pinball unit tests |
| 5 Reserve optimiser | Reserve, surplus, allocator, insufficient-funds states | `src/engine/{reserve,optimize}` | never breaches reserve/capacity (property tests) |
| 6 Digital twin & stress | Scenario simulator, policy comparison | `src/engine/simulate` | seeded regression tests |
| 7 Analytics & explainability | Metrics vs baselines, decision explanations | UI + engine | numbers traceable to records |
| 8 Security & reliability | Rate limits, input hardening, audit, e2e | API layer | security checklist, e2e |
| 9 Deploy & demo | Vercel deploy, demo script | config, docs | live URL, env documented |

Definition of done (all phases): code merged, tests pass, docs updated, no fabricated performance numbers.

Phase 1 note: shadcn/ui-style primitives (`cva` + `cn`) are hand-written in `src/components/ui/primitives.tsx` rather than generated by the shadcn CLI; the CLI can be adopted later without API changes.

Dependencies: 2 needs Firebase project credentials (user-provided); phases 4-6 depend on 3.
